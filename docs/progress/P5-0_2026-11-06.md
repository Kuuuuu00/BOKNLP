## 7. 계획 대비 변경점
- 키는 `sent_id` 단독이 아니라 (meeting_date, sent_id)다. 회의마다 `sent_id`가 1부터 다시 시작하기 때문이다(plan.md 출력 열 `sent_id`에 `meeting_date`를 더함).
- `--kind val`은 아직 구현하지 않았다(LLM 토픽 필요, P5-a 이후). 대신 제외 로직 `excluded_keys()`, `eligible_for_validation()`을 같은 스크립트에 만들어 두었다(검증 풀 9,954 → 9,914).
- 개발 표본은 고정되어 있어 `topic_dev_sample_ids.csv`가 있으면 스크립트가 다시 뽑기를 거부한다.
