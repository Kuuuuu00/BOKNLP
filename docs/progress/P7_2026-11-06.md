## 8. 점검 결과
- 결측: 정례 162회 모두에서 `dY3`, `dY10`, `d_i`, `dUST2_lag`, `dUST10_lag`, `spread_lag` 결측 0. 모든 회의일이 한국 영업일(ECOS 국고채 계열에 있음).
- `d_i ≠ 0` 34회: +25 17, −25 15, +50 2. 정례 회의일이 아닌 날의 기준금리 변경은 **1건**(2020-03-17 −50bp, 긴급회의 2020-03-16 다음 날). 정례 회의 변경 34건은 모두 **회의 당일 계열에 반영**된다. 긴급 인하는 다음 정례 회의(2020-04-09)에서 `bok_rate_prev = bok_rate = 0.75`, `d_i = 0`이라 섞이지 않는다.
- 의사록 결정문 대조(`20b`): PDF 결정문을 읽을 수 있는 129회는 방향·폭·수준 모두 일치, 불일치 0. 확인 불가 33회(2023.4 이후 PDF에는 결정문 상자가 없음 등), 그중 `d_i≠0`은 9회(2010-11-16, 2011-01-13, 2011-03-10, 2024-10-11, 2024-11-28, 2025-02-25, 2025-05-29, 2026-07-16, 2026-08-27)이다. 결정 사실은 ECOS 계열이 일관되지만 이 9회는 의사록으로 확인하지 못했다(확인 불가).
- 정렬 함수 `us_prev_bday`: 월요일 회의, 미국 휴장(추수감사절 다음 날), 계열 시작 단위 테스트 통과(스크립트 시작 시 자동 실행).
- `D_freq` = `freq_regime` 일치. 역전 구간: 3차 2018-04-12~2020-02-27 **16회**(추정 약 16 일치), 4차 2022-08-25~2026-08-27 **33회**(추정 약 34, 차이 1회). 차이는 2022-07-13 회의에서 `Spread_{t-1} = 1.75 − 1.75 = 0.00`이라 `Spread < 0` 정의에서 비역전이기 때문이다. 달력상 `Spread < 0`인 첫 날은 2018-03-22와 2022-07-28이다. 4차 구간의 마지막 달력일(2026-11-03)은 데이터 종료로 잘린 값이다.
- `ko_release_dates.csv` 28회 공개일 모두 한국 영업일(ECOS 국고채 계열에 존재), `meeting_master` 2023-04-11 이후 28회와 1:1.
